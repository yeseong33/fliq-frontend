Fliq 계정 및 데이터 삭제 안내

앱 이름: Fliq · 개발자: Fliq Team · 문의: fliq.support@gmail.com

본 페이지는 Fliq 앱 사용자가 계정과 관련 데이터를 삭제 요청할 수 있는 절차와, 삭제 시 처리되는 데이터 항목을 안내합니다.

1. 계정 삭제 요청 방법

방법 1. 앱 내에서 즉시 삭제 (권장)

  1. Fliq 앱을 실행하고 로그인합니다.
  2. 하단 탭의 마이 화면으로 이동합니다.
  3. 화면 하단의 회원 탈퇴 버튼을 누릅니다.
  4. 안내 모달에서 탈퇴를 선택합니다.
  5. Passkey 재인증이 완료되면 즉시 처리됩니다.

방법 2. 이메일로 요청 (앱 접근이 어려운 경우)

  • 수신처: fliq.support@gmail.com
  • 제목: 계정 삭제 요청
  • 본문에 가입 시 사용한 이메일 주소를 기재해 주세요.
  • 본인 확인 후 영업일 기준 7일 이내에 처리됩니다.

2. 삭제 및 보관되는 데이터

즉시 삭제완전히 삭제되는 데이터

  • Passkey(WebAuthn) 인증 정보
  • 등록한 계좌 정보
  • 푸시 알림 토큰

익명화익명화되어 보관되는 데이터

  • 참여했던 모임 정보 및 비용·정산 내역

다른 참여자의 정산 정합성 유지를 위해 보존되며, 이름과 이메일은 “탈퇴 회원”으로 대체되어 본인을 식별할 수 없습니다.

법령 보관관련 법령에 따라 분리 보관되는 데이터

  • 거래 관련 기록 — 전자상거래법에 따라 5년
  • 서비스 접속 기록 — 통신비밀보호법에 따라 3개월

법정 보관 기간이 경과하면 즉시 파기됩니다.

기기 측기기에 남는 데이터

기기 OS(Android/iOS) 의 비밀번호 관리자에 저장된 Passkey 는 자동으로 삭제되지 않습니다.
설정 → 비밀번호 (또는 비밀번호 관리자) 에서 fliq-it.com 항목을 직접 삭제해 주세요.

3. 문의

삭제 요청 처리 상태 또는 데이터 관련 문의는 fliq.support@gmail.com 으로 연락해 주세요.
